📚 Descripción del Proyecto

Este proyecto implementa un sistema de gestión de biblioteca utilizando Java y los principios de Programación Orientada a Objetos (POO), incluyendo herencia y polimorfismo.

⚙️ Funcionalidades

  • Registro de libros
  • Registro de usuarios
  • Préstamo de libros
  • Devolución de libros
  • Búsqueda de libros
  • Visualización de disponibilidad
  • Control de máximo 3 préstamos

🧠 Conceptos Aplicados

  • Encapsulamiento
  • Herencia (Persona → Usuario)
  • Polimorfismo
  • Clases y objetos

🛠️ Tecnologías

  • Java
  • POO
  • HTML, CSS, JavaScript
