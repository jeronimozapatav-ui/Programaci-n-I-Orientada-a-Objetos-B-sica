📚 Proyecto: Sistema de Biblioteca

Este proyecto implementa un sistema robusto de gestión utilizando Java y los principios fundamentales de la POO, permitiendo una administración eficiente de recursos y usuarios.

⚙️ Funcionalidades

  • Registro de libros y usuarios
  • Préstamo y devolución de libros
  • Búsqueda por título o autor
  • Visualización de disponibilidad
  • Control de máximo 3 préstamos
  • Validación de stock en tiempo real

🧠 Conceptos Aplicados

  • Encapsulamiento: Atributos privados.
  • Herencia: Relación Persona → Usuario.
  • Polimorfismo: Sobrescritura y sobrecarga de métodos.
  • Abstracción: Modelado de entidades.
